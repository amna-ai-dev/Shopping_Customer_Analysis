# Customer Shopping Analysis

## Project Overview
This project analyzes shopping data of five customers using Python.

## Features
- Displays customer shopping data
- Categorizes spending as High or Low
- Creates a bar chart
- Sorts customers by spending
- Finds the highest and lowest spending
- Counts total customers

## Technologies Used
- Python
- Pandas
- Matplotlib

## How to Run
1. Install the required libraries:
   `py -m pip install pandas matplotlib`

2. Run the project:
   `py shopping_analysis.py`
